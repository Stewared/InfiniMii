# Checked FFL source evidence

This small directory is intentionally part of the LTD runtime, despite its
historical name. Hash-bound renderer contracts refer to these two source files
by their existing relative paths:

- `src/Shader.cpp`
- `ffl/src/FFLiCharModelCreator.cpp`

Only the referenced files and their licenses are included. This is not a build
checkout or a temporary-output directory.
